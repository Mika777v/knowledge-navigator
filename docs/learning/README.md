# 学習用の資料

このリポジトリの実装を教材にして、使っている言語・フレームワークを学ぶための資料。

| 資料 | 内容 |
|---|---|
| [TYPESCRIPT.md](./TYPESCRIPT.md) | frontend の実際のコードで学ぶ TypeScript の教科書（12 章・練習問題つき） |
| [notes/](./notes/) | PR ごとの実装の解説。その PR で使った言語独特の動き・書き方（ファイル名の日付順） |

解説（`notes/`）は、実装の PR を作るときに同じ PR で足す決まり（[CLAUDE.md](../../CLAUDE.md) の「実装の解説」）。
